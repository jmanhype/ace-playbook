### **Phase 2: Single Video Generation**
```

Process:
  1. Normalize image inputs (1-7 images)
  2. Call xAI Grok Imagine Video API
  3. Wait for generation (20-25 seconds)
  4. Validate output with QC

Time: ~21 seconds
```

```
Input: Character bible + episode scripts

  3. Generate videos using multi-image method
  4. Validate character consistency across shots
  5. Combine shots into episodes
Output: Episode-length videos with character continuity
Time: ~21 seconds per 5-second shot
```

### **Phase 4: QC Validation**
```
Input: Generated video or image
Process:
  1. Score on 4 dimensions (1-10 each)
  2. Check against CHAI specs
  3. Validate aesthetic fidelity
  4. Approve if ≥ 8.0/10
  5. Refine if below threshold
Output: Quality score + approval/rejection
Time: ~30 seconds
```

### **Phase 5: Series Production**
```
Input: Character bible + series narrative
Process:
  1. Create series outline with episode structure
```
