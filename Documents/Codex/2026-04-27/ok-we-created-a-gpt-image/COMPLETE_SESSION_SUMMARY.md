```bash
# Temporary

# Permanent
echo "kernel.apparmor_restrict_unprivileged_userns = 0" | \
  sudo tee /etc/sysctl.d/99-codex-app-server.conf
```

### 2. Deep Research on AppArmor + Ubuntu 24.04

**What We Discovered**:

Ubuntu 24.04 introduced a **breaking change** that affects many tools:

**The Issue**:
```
kernel.apparmor_restrict_unprivileged_userns = 1  # NEW IN 24.04
```

This blocks:
- Bubblewrap (used by Codex, Flatpak, etc.)
- Docker/Podman in some configurations
- Container runtimes
- Development tools requiring user namespaces

**How We Found It**:
1. Surface troubleshooting failed (checked sysctl, subuid, capabilities)
2. Deep research checked kernel logs → found AppArmor DENIAL messages
3. Web search revealed this is a known Ubuntu 24.04 issue
4. Simple sysctl change fixed everything

**Impact**: This affects ALL Ubuntu 24.04 systems using these tools.

```bash

  "A futuristic eco-city with vertical gardens" \
  --iterations 3
```

**Features**:
- Automated GPT-5.4 → Grok 4.3 → GPT-5.4 pipeline
- Multiple iterations with automatic refinement
- Saves all images to output directory
- Creates pipeline history JSON
- Tracks evolution across iterations

**Pipeline Flow**:
```
Iteration 1: GPT-5.4 generates
           ↓
Iteration 1: Grok 4.3 analyzes & critiques
           ↓
Iteration 2: GPT-5.4 refines based on Grok's feedback
           ↓
Iteration 2: Grok 4.3 reviews improvements
           ↓
Iteration 3: GPT-5.4 final polish
           ↓
Output: All iterations saved + history JSON
```
