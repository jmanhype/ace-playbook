## Franchise Decision Scorecard

Score every completed viral run 1-10:

| Criterion | Question |
|---|---|
| Series Potential | Can this become at least 3 episodes? |
| Format Fit | Does it fit an existing SGFLIX show? |
| Asset Reuse | Can the character, location, look, or caption format be reused? |
| Hook Strength | Does the first frame explain the joke instantly? |
| Risk | Is it legally/platform/taste risky? Lower risk is better. |
| Factory Value | Can this become a Skool or AI Video Factory lesson? |

Decision:

| Result | Rule |
|---|---|
| Franchise | High hook, high reuse, high series potential, manageable risk. |
| Mini-series | Strong hook and 3-6 episode potential, but not endless. |
| One-off | Strong viral hit but low reuse. |
| Kill/Reframe | Too risky, confusing, weak first frame, or no repeat value. |

## Weekly Operating Rhythm

Daily:
- Run the Viral Engine on current events.
- Produce one first-frame candidate.
- Score it and tag it.

Every 2-3 days:
- Continue one existing franchise with a sequel.
- Do not only chase new topics.

Weekly:
- Pick one best-performing run and turn it into an AI Video Factory / Skool breakdown.
- Update the Franchise Vault with performance notes.
